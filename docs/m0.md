# Milestone 0

**One command to a working Qt build environment on Windows, proven by building QGLogger.**

QGLogger is, for now, an empty window. That is deliberate: Milestone 0 proves the *build* can be handed to
someone else before there is an application worth handing over.

It is checked on a clean Windows machine by following the steps as written: the
[developer setup](../README.md#developer-setup-windows) and QGSDK's check (`tests\windows-check.ps1`),
then QGLogger's own build and packaging steps from its README.

## Status

Met on 2026-10-02: QGSDK and QGLogger `main` on Windows 11 Enterprise 24H2, a fresh VM with nothing
installed beforehand.

Since then, QGLogger's versioned installers (0.0.6 to 0.0.9, 2026-10-04) have been built the same way, each on a fresh Windows clone, and published as signed releases.
